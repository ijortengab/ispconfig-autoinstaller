Auto Install Postfix with default version.

Usage: rcm postfix init [options]

Options:
   --main-mailer-type=TYPE
        Select the Mailer Type in a Postfix Installation.
        Available values: [1].
        [1]: Internet site
   --mailname=FQDN
        The Fully Qualified Domain Name (FQDN) of the mail server (e.g., smtp.example.com).
        Value available from command: hostname(-f), or other.
   --dbms=DB
        Select database management system to store the data.
        Values available from command: rcm(plugin list postfix/dbms).
   --public-domain
        Make sure that --mailname is public domain, this will trigger TLS request and DNS verification.
   --acme-client=TLS
        Select acme client to obtain TLS Certificate.
        Values available from command: rcm(plugin list acme-client).
        Conditional: Bypass if --public-domain is not added.

Additional Options:
   rcm(-p plugin prompt acme-client [--acme-client] obtain)

Global Options:
   --version
        Print version of this script.
   --help
        Show this help.
